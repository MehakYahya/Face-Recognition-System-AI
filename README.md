# Real-Time Face Recognition Attendance System

A Python-based real-time face recognition system using OpenCV and TensorFlow for student attendance management. It detects faces from a webcam, recognizes them using a trained CNN model, and logs attendance in a CSV file.


## Model

Built with TensorFlow/Keras.

CNN using Conv2D, MaxPooling2D, Flatten, Dense layers.

Trained on face images resized to 128x128 pixels.

## Output
Webcam shows recognized name overlay.

Attendance is saved in results/attendance.csv.

## Dependencies
* Python 3.x

* OpenCV

* TensorFlow

* Pandas

* NumPy
